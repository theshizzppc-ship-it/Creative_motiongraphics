# Creative motion graphics — studio project

This folder makes short Vox-style paper-collage explainer videos with the
`collage` skill in `.claude/skills/collage/`.

When the user asks for a video, a collage, or a Vox-style explainer, invoke
the `collage` skill and follow its steps. Each film is built in its own
`collage-<topic-slug>/` folder.

Never submit paid generations to any platform from here. The collage skill
uses only free tools (Wikimedia photos, HyperFrames, ffmpeg).

`projects/` holds earlier work from the retired vox-animation flow; leave it
untouched unless the user asks.
